# بناء تطبيق "جزء تبارك وعمّ" كملف APK

هذا مشروع أندرويد جاهز. التطبيق يحمّل ملف HTML أوفلاين بالكامل من داخل التطبيق
(لا يحتاج إنترنت إطلاقاً — حتى صلاحية الإنترنت غير مطلوبة).

## الطريقة الأسهل (Android Studio — مجاني)

1. نزّل وثبّت **Android Studio** من: https://developer.android.com/studio
2. افتحه واختر **Open** ثم اختر مجلد `QuranTabarak` هذا.
3. انتظر حتى ينتهي Gradle Sync (أول مرة يحمّل أدوات أندرويد تلقائياً — يحتاج إنترنت مرة واحدة فقط أثناء البناء).
4. من القائمة العليا: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. عند الانتهاء تظهر رسالة بزر **locate** — اضغطه للوصول للملف:
   `app/build/outputs/apk/debug/app-debug.apk`
6. انسخ هذا الملف لهاتفك وثبّته (فعّل "تثبيت من مصادر غير معروفة" عند الطلب).

## ملاحظات

- نسخة الـ **debug APK** موقّعة تلقائياً وتثبّت على أي جهاز مباشرة — مناسبة للاستخدام الشخصي.
- لو أردت نسخة **release** للنشر على المتجر، ستحتاج إنشاء مفتاح توقيع (keystore) من
  **Build → Generate Signed Bundle / APK**.
- زر النطق الصوتي يعتمد على Web Speech API؛ قد لا يعمل داخل WebView على كل الأجهزة.
  لو احتجت نطقاً يعمل بضمان داخل التطبيق، أخبرني لأربط محرّك النطق الأصلي (Android TTS).

## تعديل المحتوى لاحقاً

لتحديث محتوى التطبيق، استبدل الملف:
`app/src/main/assets/index.html`
بأي نسخة HTML جديدة، ثم أعد بناء الـ APK.

الإصدارات والإعدادات في: `app/build.gradle` (versionCode / versionName).
